## Task 3 — Zigbee TX power 18 → 20 ✅

SLZB (CC2652P) รองรับ +20dBm ช่วยตัวไกลอย่างเตาไฟฟ้า (LQI 40)

```bash
# แก้ config (host path, ไฟล์: /volume1/docker/zigbee2mqtt/configuration.yaml)
/c/Windows/System32/OpenSSH/ssh.exe -o StrictHostKeyChecking=no drydream@192.168.1.170 \
  "sed -i.bak-20260818 's/transmit_power: 18/transmit_power: 20/' /volume1/docker/zigbee2mqtt/configuration.yaml && \
   grep transmit_power /volume1/docker/zigbee2mqtt/configuration.yaml && \
   sudo /usr/local/bin/docker restart zigbee2mqtt"
```

Verify: รอ ~1 นาที แล้ว `sudo /usr/local/bin/docker logs zigbee2mqtt --tail 20` — ต้องเห็น started, ไม่มี error (log หลักอยู่ที่ `/volume1/docker/zigbee2mqtt/log/<latest>/log.log`)

**ผล:** `transmit_power: 20` apply แล้ว, container restart สำเร็จ (up, stable). error ที่เห็นตอน restart (`ไฟบันไดชั้นบน/ล่าง`, `ไฟห้องนอน`, `ไฟเตียง` — "no output cluster genOnOff" / bind INVALID_EP) เป็นปัญหา config เดิมของอุปกรณ์เหล่านั้น ไม่เกี่ยวกับ TX power, เกิดซ้ำทุกครั้งที่ configure extension รัน ไม่ใช่ crash loop บันทึกค่าไว้ถาวรที่ `docs/zigbee-devices.md`. **verify ผลจริง (LQI เตาไฟฟ้าดีขึ้น) ยังต้องรอ 2-3 วัน**
